# Behavioral test coverage

`./tests/run.sh` is the entry point; CI runs it with `--ci` on Linux and
macOS. The pre-commit hooks run the same focused tests when their production
sources change.

The suites read only the frozen fixtures in `tests/fixtures/`.
`claude-settings.json` there holds only the Claude Code wiring of the three
helpers, in the home-relative form README.md describes.
Checks of what a consumer's own data contains and how it wires the kit stay
with that consumer.

Shell line-coverage is not used as a hard gate: these programs mix sourced
POSIX shell, Bash, Python, Node and child processes, for
which one percentage would omit meaningful branches. Coverage is tracked as a
source-to-test behavior matrix instead.
